## 快速安装

1. 下载并解压工具包
2. 运行 `_BsKeyTools.exe`
3. 选择 3ds Max 版本，点击安装
4. 重启 3ds Max
5. 菜单栏 → `BsKeyTools` → ` BsKeyTools`

自动/手动安装、更新、卸载等详细说明请查看 [安装指南](/tools/bskeytools/install)
